# Как добавить песню

1. Положи `.mp3` файл в эту папку (`music/`).
2. Открой `playlist.json` и добавь запись в массив `tracks`:

   ```json
   { "file": "Имя_Файла.mp3", "title": "Название для показа" }
   ```

   - `file` — имя файла ровно как в папке (регистр важен).
   - `title` — что увидят на странице.

3. (Необязательно) поменяй `"default"` на имя файла, который должен
   грузиться при открытии страницы. Сейчас это `Juicy_Dark_Horse.mp3`
   (Dark House).

Всё. Никакой пересборки — плейлист подхватывается автоматически при
загрузке страницы. Если `playlist.json` не удалось прочитать, плеер
откатывается на дефолтный трек, страница не ломается.
