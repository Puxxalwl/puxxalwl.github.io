# Puxxalwl — личный сайт

Статическая двуязычная биография без сборки и зависимостей: русский язык используется по умолчанию, английский включается кнопкой EN. Для GitHub Pages достаточно публикации корня репозитория; существующий способ развёртывания менять не требуется.

## Локальный просмотр

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000. Команда не публикует сайт.

## Редактирование

- Биография, проекты, контакты и метаданные находятся в [index.html](index.html).
- Палитра, сетка и адаптивные правила — в [styles.css](styles.css).
- [js/main.js](js/main.js) применяет сохранённые тему и язык. Русский — язык по умолчанию, выбор английского сохраняется в браузере. Без сохранённого выбора темы используется настройка ОС. Без JavaScript русский контент и ссылки доступны, тема определяется CSS.
- Шрифты системные. Внешних шрифтов, аналитики, библиотек и запросов к GitHub при загрузке нет.
- Возраст намеренно не указан: не требуется ежегодно обновлять биографию. Из личных деталей оставлены имя Руслан и любимая книга Mushoku Tensei.

## Содержание и источники

Stille описан как командный open-source проект; участие автора — ядро и Android-клиент. Отсутствие центральных серверов обозначает направление проекта, а не обещание соединения в любой сети. Упомянуты прямой маршрут и собственный ретранслятор, без заявлений об аудите или гарантиях безопасности.

- [Stille Messenger Core](https://github.com/Puxxalwl/stille-messenger-core)
- [Android-клиент](https://github.com/Puxxalwl/Stille-Messenger-Android)
- [Volt.NET](https://github.com/Puxxalwl/Volt.NET)
- [Профиль XERJ](https://hub.xerj.org/contributors/Puxxalwl)

Volt.NET не отождествлён с прежним PowerBot: подтверждения, что это один проект, не найдено. Имя Ruslan и контакты перенесены из прежней страницы. Устаревшие возраст, стек и ссылки на сообщества не перенесены.

## Проверки редизайна

В Chromium через Playwright проверены ширины 320, 360, 390, 680, 768, 1024, 1440 и 1920 px, отсутствие горизонтального переполнения, переход к содержимому с клавиатуры, якорные ссылки, переключение и сохранение темы, системная тёмная тема, уменьшение движения и работа без JavaScript. axe-core не обнаружил нарушений в проверенных светлой и тёмной темах (WCAG 2 A/AA, WCAG 2.1 AA и best practices). Ошибок JavaScript и внешних сетевых запросов при проверке не было.

Это автоматические проверки, а не полная сертификация доступности. Safari, Firefox, физические мобильные устройства и внешний почтовый/Telegram-клиент отдельно не проверялись. Снимки страницы сделаны браузером; визуальная оценка изображений в среде агента недоступна.

Временные инструменты и снимки находятся в исключённом из Git каталоге `.tools/`; они не нужны для работы сайта.
